## 2. 페이지별 상세 설계

### P-01. 랜딩 페이지 (`/`)

**목적:** 서비스 소개 및 가입 유도

**구성 요소:**
- 헤더: 로고 + 로그인 버튼
- 히어로 섹션: 서비스 핵심 문구 + CTA 버튼
- 기능 소개 섹션: 3단계 설명 (업로드 → AI 캡션 → 자동 업로드)
- 대상 고객 섹션: 카페/식당/베이커리 타겟
- 푸터: 이용약관, 개인정보처리방침

**CTA 버튼:** "무료로 시작하기" → `/signup`

---

### P-02. 로그인 (`/login`)

**목적:** 기존 사용자 로그인

**구성 요소:**
- 로고 + 서비스명
- 이메일 입력 필드
- 비밀번호 입력 필드 (보기/숨기기 토글)
- 비밀번호 찾기 링크
- 로그인 버튼
- 구분선 ("또는")
- 구글 로그인 버튼
- 카카오 로그인 버튼
- 네이버 로그인 버튼
- 회원가입 링크

**유효성 검사:**
- 이메일 미입력 / 형식 오류
- 비밀번호 6자 미만
- 로그인 실패 시 에러 메시지

**성공 후:** `/dashboard` 이동

---

### P-03. 회원가입 (`/signup`)

**목적:** 신규 사용자 계정 생성

**구성 요소:**
- 이름 입력 필드
- 이메일 입력 필드
- 비밀번호 입력 필드 (강도 표시)
- 비밀번호 확인 필드
- 이용약관 동의 체크박스
- 회원가입 버튼
- 구글 / 카카오 / 네이버 소셜 가입 버튼

**유효성 검사:**
- 이메일 중복 확인 (실시간)
- 비밀번호 8자 이상, 강도 표시 (약함 / 보통 / 강함)
- 비밀번호 일치 확인
- 약관 동의 필수

**성공 후:** `/dashboard` 이동

---

### P-04. 대시보드 (`/dashboard`)

**목적:** 서비스 메인 화면 — 현황 요약 + 빠른 실행

**구성 요소:**
- 상단 네비게이션: 로고, 메뉴 (업로드 / 히스토리 / 설정), ThemeToggle(🌙/☀️), LangToggle(KO/EN), 프로필
- 요약 카드 (3개):
  - 이번 달 업로드 수
  - 예약 중인 게시물 수
  - 연동된 인스타 계정 수
- 빠른 업로드 버튼: "새 게시물 만들기"
- 최근 업로드 목록 (최대 5개)
- 인스타 계정 미연동 시: 연동 유도 배너

---

### P-05. 사진 업로드 (`/upload`)

**목적:** 게시물 이미지 업로드

**구성 요소:**
- 드래그&드롭 영역 (점선 테두리)
- 파일 선택 버튼
- 이미지 미리보기 (업로드 후)
- 이미지 규격 안내 (1080x1080 권장)
- 다음 버튼 → P-06 이동

**지원 형식 안내:** JPG, PNG, WEBP / 최대 10MB

---

### P-06. AI 캡션 생성 (`/upload/caption`)

**목적:** AI가 생성한 캡션과 해시태그 확인 및 수정

**구성 요소:**
- 업로드한 이미지 미리보기 (좌측)
- 우측 편집 영역:
  - 캡션 텍스트 영역 (수정 가능)
  - 해시태그 목록 (태그 형태, 개별 삭제 가능)
  - "다시 생성" 버튼
- 하단 버튼:
  - "즉시 업로드" → 바로 인스타 게시
  - "예약 설정" → P-07 이동

**로딩 상태:** AI 생성 중 스피너 + "캡션을 만들고 있어요..." 문구

---

### P-07. 예약 업로드 (`/upload/schedule`)

**목적:** 업로드할 날짜와 시간 설정

**구성 요소:**
- 이미지 + 캡션 미리보기 (요약)
- 날짜 선택 (캘린더 피커)
- 시간 선택 (시/분 드롭다운)
- 선택된 예약 시간 표시
- "예약 확정" 버튼 → P-08 이동
- "취소" 버튼 → P-06 이동

**제약:** 현재 시간 + 10분 이후만 선택 가능

---

### P-08. 업로드 완료 (`/upload/done`)

**목적:** 즉시 업로드 또는 예약 완료 확인

**구성 요소:**
- 완료 아이콘 (체크)
- 완료 메시지:
  - 즉시: "인스타그램에 업로드됐어요!"
  - 예약: "2025년 3월 15일 오전 10:00에 업로드할게요!"
- 업로드된 이미지 썸네일
- 버튼 2개:
  - "인스타그램에서 보기" (즉시 업로드 시에만)
  - "새 게시물 만들기" → `/upload`
  - "히스토리 보기" → `/history`

---

### P-09. 히스토리 (`/history`)

**목적:** 전체 게시물 목록 관리

**구성 요소:**
- 필터 탭: 전체 / 업로드 완료 / 예약 중 / 실패
- 게시물 카드 목록:
  - 이미지 썸네일
  - 캡션 미리보기 (2줄)
  - 상태 배지 (완료 / 예약 / 실패)
  - 업로드 시간
  - 액션 버튼 (수정 / 삭제 / 인스타 링크)
- 실패한 게시물: "재시도" 버튼 표시

---

### P-10. 설정 (`/settings`)

**목적:** 계정 및 인스타그램 연동 관리

**섹션 구성:**

**프로필 설정:**
- 이름 수정
- 이메일 확인 (변경 불가)

**플랜 관리 (PlanSection):**
- 현재 플랜 뱃지 (무료 / 프로)
- 플랜 비교 카드 2개 (무료 / 프로)
- 업그레이드 버튼 (현재 결제 연동 전 — 안내 토스트 표시)
- 다운그레이드 버튼 (프로 → 무료)

**인스타그램 연동:**
- 연동된 계정 목록 (아이디)
- 연동 해제 버튼
- "새 계정 연동" 버튼

**계정 관리:**
- 비밀번호 변경 (이메일 가입자만, 현재 미구현 — 비활성화)
- 로그아웃 버튼
- 회원 탈퇴 링크 (현재 미구현 — 비활성화)

---

### P-12. 이미지 편집 (`/upload/edit`)

**목적:** 이미지 업로드 전 Canvas API로 이미지를 편집합니다.

**진입:** P-05(사진 업로드) "다음" 버튼 → 파일 ObjectURL + accountId 전달

**구성 요소:**
- 좌측/상단: 편집 미리보기 (Canvas, 최대 480px, 편집 실시간 반영)
- 우측/하단 컨트롤 패널:
  - **비율 크롭** 버튼 4종: 원본 / 1:1 / 4:5 / 1.91:1
  - **필터 프리셋** 버튼 5종: 감성 / 밝음 / 빈티지 / 선명 / 따뜻함
  - **조정 슬라이더** 3종:
    - 밝기 (0 ~ 200, 기본 100)
    - 대비 (0 ~ 200, 기본 100)
    - 채도 (0 ~ 200, 기본 100)
  - **편집 초기화** 버튼: 슬라이더·필터를 기본값으로 리셋
  - **다음** 버튼: 편집본 `canvas.toBlob()` → `POST /api/posts/upload` → P-06 이동

**상태:**
- 이미지 로딩 중: Spinner 표시
- 업로드 중: "업로드 중..." 버튼 비활성화
- 실패: 토스트 에러 메시지

**다크모드:** 캔버스 wrap, 칩 버튼, 슬라이더 모두 CSS 변수 대응

---

### P-13. 분석 대시보드 (`/analytics`)

**목적:** 서비스 DB 기반으로 업로드 현황을 시각화합니다 (Meta API 불필요).

**진입:** NavBar "분석" 메뉴

**구성 요소:**
- **이번 달 요약 카드 3개** (가로 배열):
  - 업로드 수 (이번 달)
  - 업로드 성공률 (%)
  - 예약 비율 (%)
- **월별 업로드 추이** (full-width 섹션):
  - 최근 12개월 bar chart
  - X축: "MM월" 형식 (연도 표시 없음), Y축: 건수
  - 빈 달은 0으로 표시
- **요일별 업로드 패턴** (half 섹션):
  - 업로드 완료(posted) 기준 요일별 bar chart
  - 일~토, 보라색 계열 바
- **업로드 성공률** (quarter 섹션):
  - posted / (posted + failed) donut pie chart
  - 성공(초록) / 실패(빨강) 색상
- **예약 vs 즉시 업로드** (quarter 섹션):
  - 예약 경험 게시물 / 전체 게시물 donut pie chart
  - 예약(파랑) / 즉시(회색) 색상

**데이터 없음 상태:** 각 섹션에 "아직 데이터가 없어요." 표시

**다크모드:** 차트 색상 CSS 변수 대응, recharts Tooltip 배경 `var(--color-bg-card)` 적용

**다국어:** `analytics.*` 번역 키 전체 지원

### P-11. 콘텐츠 캘린더 (`/calendar`)

**목적:** 예약된 게시물을 월간 달력으로 시각화하고 일정을 조정합니다.

**구성 요소:**
- 상단: 이전/다음 월 이동 버튼 + 연/월 표시 (예: "2026년 7월")
- 범례: 예약 중 (파랑) / 업로드 완료 (초록) / 실패 (빨강) + 드래그 힌트
- 달력 그리드 (7열):
  - 요일 헤더 행 (일 ~ 토)
  - 날짜 셀: 날짜 숫자 + 해당 날 예약 항목 목록
  - 오늘 날짜 강조 (날짜 숫자에 Primary 색상 원)
- 예약 항목 칩: 썸네일 + 시간 + 상태별 색상
- 드래그&드롭: `pending` 항목만 드래그 가능, 날짜 셀에 드롭
- 상세 모달 (항목 클릭 시):
  - 이미지 (상단 전체 너비)
  - 캡션, 상태 배지, 예약 시간
  - "예약 취소" 버튼 (pending 상태만) + "닫기" 버튼

**상태 색상 (CSS 커스텀 변수):**
- `pending` → `--cal-pending-bg / --cal-pending-text` (파랑 계열)
- `done` → `--cal-done-bg / --cal-done-text` (초록 계열)
- `failed` → `--cal-failed-bg / --cal-failed-text` (빨강 계열)

**드래그 제약:** 드롭 목표 날짜 + 원본 시간이 현재 시각 + 10분 이전이면 오류 토스트 표시

## 3. 공통 컴포넌트

| 컴포넌트 | 사용 위치 |
|---------|----------|
| 상단 네비게이션 (NavBar) | P-04 ~ P-13 (분석 링크 추가) |
| ThemeToggle (🌙/☀️) | NavBar, 랜딩 페이지 헤더 |
| LangToggle (KO/EN) | NavBar, 랜딩 페이지 헤더 |
| OnboardingModal | P-04 대시보드 (신규 사용자 첫 방문 시 1회) |
| PlanSection | P-10 설정 페이지 |
| 로딩 스피너 (Spinner) | AI 생성, 업로드 중, 데이터 로딩 |
| 토스트 메시지 (Toast) | 성공 / 실패 알림 |
| 모달 (ConfirmModal) | 삭제 확인, 연동 해제 확인 |
| 빈 상태 화면 (EmptyState) | 히스토리 없을 때 |
| ErrorBoundary | 전체 앱 (예상치 못한 에러 포착) |

### 다크모드 / 언어 전환

- `ThemeContext` 가 `<html>` 요소에 `data-theme='dark'` 속성을 적용한다.
- CSS 커스텀 변수 (`:root` / `[data-theme='dark']`) 로 전체 색상 관리.
- `LangToggle` 클릭 시 `i18n.changeLanguage()` 호출, localStorage 'lang' 키 저장.
- 두 버튼 모두 NavBar와 랜딩 페이지 헤더에 동일하게 노출된다.

## 4. 화면 흐름

```
랜딩 → 회원가입/로그인 → 대시보드
                               ↓
                         사진 업로드
                               ↓
                        이미지 편집 (NEW)
                               ↓
                        AI 캡션 생성
                         ↙         ↘
                   즉시 업로드    예약 설정
                         ↘         ↙
                          업로드 완료
                               ↓
                     히스토리 / 대시보드
```
