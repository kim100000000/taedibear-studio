## 2. 페이지별 상세 설계

### P-01. 랜딩 페이지 (`/`)

**목적:** 서비스 소개 및 가입 유도

**구성 요소:**
- 헤더: 로고 + 로그인 버튼
- 히어로 섹션: 서비스 핵심 문구 + CTA 버튼
- 기능 소개 섹션: 3단계 설명 (업로드 → AI 캡션 → 자동 업로드)
- 대상 고객 섹션: 카페/식당/베이커리 타겟
- 푸터: 이용약관, 개인정보처리방침

**CTA 버튼:** "무료로 시작하기" → `/signup`

---

### P-02. 로그인 (`/login`)

**목적:** 기존 사용자 로그인

**구성 요소:**
- 로고 + 서비스명
- 이메일 입력 필드
- 비밀번호 입력 필드 (보기/숨기기 토글)
- 비밀번호 찾기 링크
- 로그인 버튼
- 구분선 ("또는")
- 구글 로그인 버튼
- 카카오 로그인 버튼
- 회원가입 링크

**유효성 검사:**
- 이메일 미입력 / 형식 오류
- 비밀번호 6자 미만
- 로그인 실패 시 에러 메시지

**성공 후:** `/dashboard` 이동

---

### P-03. 회원가입 (`/signup`)

**목적:** 신규 사용자 계정 생성

**구성 요소:**
- 이름 입력 필드
- 이메일 입력 필드
- 비밀번호 입력 필드 (강도 표시)
- 비밀번호 확인 필드
- 이용약관 동의 체크박스
- 회원가입 버튼
- 구글 / 카카오 소셜 가입 버튼

**유효성 검사:**
- 이메일 중복 확인 (실시간)
- 비밀번호 8자 이상, 강도 표시 (약함 / 보통 / 강함)
- 비밀번호 일치 확인
- 약관 동의 필수

**성공 후:** `/dashboard` 이동

---

### P-04. 대시보드 (`/dashboard`)

**목적:** 서비스 메인 화면 — 현황 요약 + 빠른 실행

**구성 요소:**
- 상단 네비게이션: 로고, 메뉴 (업로드 / 히스토리 / 설정), 프로필
- 요약 카드 (3개):
  - 이번 달 업로드 수
  - 예약 중인 게시물 수
  - 연동된 인스타 계정 수
- 빠른 업로드 버튼: "새 게시물 만들기"
- 최근 업로드 목록 (최대 5개)
- 인스타 계정 미연동 시: 연동 유도 배너

---

### P-05. 사진 업로드 (`/upload`)

**목적:** 게시물 이미지 업로드

**구성 요소:**
- 드래그&드롭 영역 (점선 테두리)
- 파일 선택 버튼
- 이미지 미리보기 (업로드 후)
- 이미지 규격 안내 (1080x1080 권장)
- 다음 버튼 → P-06 이동

**지원 형식 안내:** JPG, PNG, WEBP / 최대 10MB

---

### P-06. AI 캡션 생성 (`/upload/caption`)

**목적:** AI가 생성한 캡션과 해시태그 확인 및 수정

**구성 요소:**
- 업로드한 이미지 미리보기 (좌측)
- 우측 편집 영역:
  - 캡션 텍스트 영역 (수정 가능)
  - 해시태그 목록 (태그 형태, 개별 삭제 가능)
  - "다시 생성" 버튼
- 하단 버튼:
  - "즉시 업로드" → 바로 인스타 게시
  - "예약 설정" → P-07 이동

**로딩 상태:** AI 생성 중 스피너 + "캡션을 만들고 있어요..." 문구

---

### P-07. 예약 업로드 (`/upload/schedule`)

**목적:** 업로드할 날짜와 시간 설정

**구성 요소:**
- 이미지 + 캡션 미리보기 (요약)
- 날짜 선택 (캘린더 피커)
- 시간 선택 (시/분 드롭다운)
- 선택된 예약 시간 표시
- "예약 확정" 버튼 → P-08 이동
- "취소" 버튼 → P-06 이동

**제약:** 현재 시간 + 10분 이후만 선택 가능

---

### P-08. 업로드 완료 (`/upload/done`)

**목적:** 즉시 업로드 또는 예약 완료 확인

**구성 요소:**
- 완료 아이콘 (체크)
- 완료 메시지:
  - 즉시: "인스타그램에 업로드됐어요!"
  - 예약: "2025년 3월 15일 오전 10:00에 업로드할게요!"
- 업로드된 이미지 썸네일
- 버튼 2개:
  - "인스타그램에서 보기" (즉시 업로드 시에만)
  - "새 게시물 만들기" → `/upload`
  - "히스토리 보기" → `/history`

---

### P-09. 히스토리 (`/history`)

**목적:** 전체 게시물 목록 관리

**구성 요소:**
- 필터 탭: 전체 / 업로드 완료 / 예약 중 / 실패
- 게시물 카드 목록:
  - 이미지 썸네일
  - 캡션 미리보기 (2줄)
  - 상태 배지 (완료 / 예약 / 실패)
  - 업로드 시간
  - 액션 버튼 (수정 / 삭제 / 인스타 링크)
- 실패한 게시물: "재시도" 버튼 표시

---

### P-10. 설정 (`/settings`)

**목적:** 계정 및 인스타그램 연동 관리

**섹션 구성:**

**프로필 설정:**
- 이름 수정
- 이메일 확인 (변경 불가)

**인스타그램 연동:**
- 연동된 계정 목록 (프로필 사진 + 아이디)
- 연동 해제 버튼
- "새 계정 연동" 버튼

**계정 관리:**
- 비밀번호 변경 (이메일 가입자만)
- 로그아웃 버튼
- 회원 탈퇴 링크

---

## 3. 공통 컴포넌트

| 컴포넌트 | 사용 위치 |
|---------|----------|
| 상단 네비게이션 | P-04 ~ P-10 |
| 로딩 스피너 | AI 생성, 업로드 중 |
| 토스트 메시지 | 성공 / 실패 알림 |
| 모달 | 삭제 확인, 연동 해제 확인 |
| 빈 상태 화면 | 히스토리 없을 때 |

---

## 4. 화면 흐름

```
랜딩 → 회원가입/로그인 → 대시보드
                               ↓
                         사진 업로드
                               ↓
                        AI 캡션 생성
                         ↙         ↘
                   즉시 업로드    예약 설정
                         ↘         ↙
                          업로드 완료
                               ↓
                     히스토리 / 대시보드
```
