# Taedibear Studio — 요구사항 명세서

**버전:** v1.0  
**작성일:** 2026-06-27  
**작성자:** @taedibear  
**프로젝트명:** Taedibear Studio  
**문서 유형:** Software Requirements Specification (SRS)

---

## 1. 문서 개요

### 1.1 목적

본 문서는 Taedibear Studio 서비스의 기능적/비기능적 요구사항을 정의합니다. 개발자, 기획자가 공통된 이해를 바탕으로 서비스를 개발할 수 있도록 작성되었습니다.

### 1.2 범위

- 서비스명: Taedibear Studio
- 서비스 유형: 소상공인 SNS 자동화 웹서비스
- 플랫폼: 웹 (PC / 모바일 브라우저)
- MVP 범위에 한정하여 작성

### 1.3 용어 정의

| 용어 | 정의 |
|------|------|
| 사용자 | Taedibear Studio에 가입한 소상공인 |
| 게시물 | 사용자가 인스타그램에 올릴 이미지 + 캡션 세트 |
| AI 캡션 | Google Gemini API가 자동 생성한 캡션 및 해시태그 |
| 예약 업로드 | 지정한 시간에 자동으로 인스타그램에 업로드되는 기능 |
| Meta API | 인스타그램 업로드에 사용하는 Meta Graph API |
| JWT | 로그인 인증에 사용하는 JSON Web Token |

## 2. 전체 시스템 개요

### 2.1 시스템 구성

```
[사용자 브라우저]
      ↕
[프론트엔드 - React]
      ↕
[백엔드 API - Node.js]
      ↕                    ↕                   ↕
[MySQL DB]          [Gemini API]        [Meta Graph API]
                                              ↕
                                      [인스타그램]
```

### 2.2 주요 사용자 흐름

1. 회원가입 / 로그인
2. 인스타그램 계정 연동
3. 사진 업로드
4. AI 캡션 + 해시태그 자동 생성
5. 즉시 업로드 또는 예약 설정
6. 히스토리 관리

## 3. 기능 요구사항

요구사항 ID 규칙: `FR-[카테고리번호]-[순번]`

- FR-1xx: 인증
- FR-2xx: 인스타그램 연동
- FR-3xx: 게시물
- FR-4xx: 예약
- FR-5xx: 사용자 관리

## 5. 제약 사항

| ID | 제약 | 내용 |
|----|------|------|
| CON-01 | Meta API 제한 | 인스타그램 비즈니스/크리에이터 계정만 API 업로드 가능 |
| CON-02 | Meta API 승인 | 앱 심사 기간 최대 2주 소요 가능 |

| CON-05 | 초기 예산 | 무료 또는 최소 비용 인프라 사용 (Vercel, Railway 무료 플랜) |
