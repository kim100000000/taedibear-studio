## 1. 개발 환경 키 발급

1. https://developers.tosspayments.com 접속 → 로그인
2. 애플리케이션 생성 → **테스트 키** 복사
   - 클라이언트 키: `test_ck_...`
   - 시크릿 키: `test_sk_...`

## 2. 환경변수 설정

**프론트엔드** — `frontend/.env.local` 생성:
```
VITE_TOSS_CLIENT_KEY=test_ck_여기에_테스트_클라이언트_키
```

**백엔드** — `.env` 또는 환경변수에 추가:
```
TOSS_SECRET_KEY=test_sk_여기에_테스트_시크릿_키
```

## 3. 테스트 방법

1. 서버 재시작 후 `/settings` → "업그레이드" 버튼 클릭
2. 토스 결제 위젯 열림 → 테스트 카드로 결제
3. `/payments/success` 리다이렉트 → Pro 플랜 전환 확인
4. `/settings` → 구독 해지 → Free 플랜 전환 확인
5. `/upload/caption`에서 10회 초과 업로드 시 UpgradeModal 노출 확인
