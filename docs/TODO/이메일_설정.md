## 1. Gmail SMTP 앱 비밀번호 발급

1. Google 계정 → https://myaccount.google.com/security
2. **2단계 인증** 활성화 (미활성화 시 앱 비밀번호 메뉴 없음)
3. https://myaccount.google.com/apppasswords 접속
4. 앱 이름 "Taedibear Studio" 입력 → **생성**
5. 16자리 비밀번호 복사 (화면에 한 번만 표시됨)

## 2. 환경변수 설정

**백엔드** — `.env` 또는 서버 환경변수에 추가:
```
MAIL_HOST=smtp.gmail.com
MAIL_PORT=587
MAIL_USERNAME=발송에_사용할_gmail_주소@gmail.com
MAIL_PASSWORD=앱-비밀번호-16자리  # 띄어쓰기 제거
MAIL_FROM=noreply@taedibear.studio
```

> `MAIL_FROM`은 수신자에게 보이는 발신자 주소.  
> Gmail 무료 계정은 실제 발송 주소가 `MAIL_USERNAME`으로 고정되므로 표시용 이름만 변경됨.

## 3. 테스트 방법

1. 환경변수 설정 후 서버 재시작
2. 예약 게시물 등록 → 인스타그램 계정 미연동 상태로 예약 시간 도래
3. 1분 cron 실행 → 3회 실패 시 등록된 이메일로 알림 수신 확인
4. 또는 `EmailService.sendUploadFailureNotification()` 직접 테스트 코드 작성
