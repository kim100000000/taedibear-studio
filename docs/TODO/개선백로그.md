# 개선 백로그 (2026-07-06 사용자 피드백 기반)

우선순위: 🔴 버그 > 🟠 저비용 고효율 > 🟡 중간 규모 > 🔵 장기

## 🔴 버그
- [ ] **리뷰 댓글 username "@?" 표시** — `ReviewsPage`가 `@{comment.username || '?'}` 렌더. Meta가 username을 안 주는 경우(권한 재연동 전, 비공개 계정) null. 재연동 후에도 재현되면 개별 댓글 조회로 보강. '?' 대신 "(알 수 없음)" 등 안내 문구로 개선
- [ ] **삭제된 댓글이 리뷰 목록에 잔존** — `ReviewService.syncComments`가 추가만 하고 삭제 동기화 없음. 동기화 시 Meta 응답에 없는 comment_id는 deleted 처리(또는 행 삭제)

## 🟠 저비용 고효율
- [ ] **리뷰 자동 답글 ON/OFF 스위치 UI** — 설정에서 현재 텍스트 표기 → 토글 스위치 + "OFF: AI 초안을 검토 후 직접 발행 / ON: 30분마다 자동 발행" 설명 문구
- [ ] **캘린더에 발행 완료 게시물 표시** — 현재 예약(scheduled)만 표시. posted 게시물도 posted_at 기준으로 표시해 "콘텐츠 달력"으로 확장 (색상으로 예약/완료 구분)
- [ ] **임시 저장 버튼 + 보관함 노출** — draft 상태는 이미 존재. 캡션 화면에 명시적 "임시 저장" 버튼, 대시보드/히스토리에 "임시 저장함" 진입점 추가
- [ ] **게시물 미리보기** — 캡션 확정 화면에 인스타그램 피드 형태 미리보기 (사진+캡션+해시태그 렌더)
- [ ] **워터마크 보상 Pro 처리** — Pro는 크레딧이 무의미하므로 토글 자체를 Free 전용으로 노출 (docs/10 7절 반영)

## 🟡 중간 규모
- [ ] **캡션 보관함(즐겨찾기)** — 마음에 든 캡션 저장 → 새 게시물 작성 시 불러오기/변형 생성. 테이블 1개 + CRUD
- [ ] **공지사항 + 문의 탭** — 공지: 관리자 작성 목록(관리자 대시보드 연계). 문의: 1단계는 이메일/카카오채널 링크, 2단계는 문의 폼+관리자 답변
- [ ] **성과 기반 캡션 개선** — 인사이트 데이터(조회/좋아요/저장)를 캡션 생성 프롬프트에 피드백: "이 계정에서 성과 좋았던 캡션 스타일 참고". 주의: 조회수는 사진/시간대/계정 규모 영향이 커서 캡션 단독 귀인 불가 — 계정별 데이터가 쌓인 뒤(게시물 20~30개+) 적용
- [ ] **도달(조회수) 개선 기능** — 사장님 게시물이 더 많이 노출되도록 돕는 기능 묶음: 해시태그 추천(업종+지역 조합, Gemini 활용), 최적 업로드 시간 제안(요일별 패턴 데이터 활용), 위치 태그 안내, 캡션에 저장/공유 유도 문구 옵션. "새 계정 첫 30일 가이드" 온보딩 콘텐츠도 후보

## 🔵 장기
- [ ] **릴스 자동 생성** — 사진 여러 장 → 템플릿 슬라이드쇼 영상(서버 ffmpeg, 텍스트 오버레이) → Meta API REELS 발행. 크레딧 3~5개 소모. Pro도 릴스는 크레딧 소모(또는 월 N회 포함) → Business 상위 플랜의 차별화 근거 (docs/10 4-4절 연계)
- [ ] **커뮤니티 탭** — 초기엔 보류 (빈 커뮤니티는 역효과 + 관리 부담). 유저 확보 후 오픈카톡/네이버카페로 시작 → 검증되면 인앱 탭

## 확인된 사항 (구현 불필요)
- **Pro 구독 시 사용량 표시**: 이미 처리됨 — Pro는 `limit=null`이라 "3 / 10" 대신 "3"(이번 달 업로드 수)만 표시, Free 배지·경고색도 사라짐
- **캡션은 매번 다르게 생성**: 사진+업종/분위기 기반이며 같은 사진도 재생성마다 다름 (의도된 동작)
- **조회수 0 원인**: (1) `instagram_manage_insights` 권한 추가 후 계정 재연동 전이라 인사이트가 안 들어옴, (2) Meta 인사이트는 발행 직후 집계 지연, (3) 새 계정·팔로워 0이면 실제 조회 0이 정상 — 캡션 문제로 단정할 수 없음
