# Taedibear Studio — 서비스 기획서

**버전:** v1.0  
**작성일:** 2026-06-27  
**브랜드:** @taedibear  

---

## 1. 서비스 개요

**Taedibear Studio**는 카페, 식당, 베이커리 등 소규모 사업자가 사진 한 장만 올리면 AI가 캡션과 해시태그를 자동 생성하고 인스타그램에 자동 업로드해주는 SNS 자동화 웹서비스입니다.

> "사장님은 가게 운영에만 집중하고, SNS는 자동으로 흘러가게 해드립니다."

---

## 2. 문제 정의

| 문제 | 내용 |
|------|------|
| 시간 부족 | 소상공인은 SNS 운영에 할애할 시간이 없음 |
| 전문성 부족 | 어떤 사진을, 어떤 캡션으로 올려야 할지 모름 |
| 비용 부담 | 기존 마케팅 대행사는 월 수십~수백만원 수준 |
| 꾸준함 부족 | 올리다가 중단하는 경우가 대부분 |

---

## 3. 솔루션

1. 사장님이 사진을 업로드
2. AI(Google Gemini API)가 업종에 맞는 캡션 + 해시태그 자동 생성
3. Meta Graph API로 인스타그램 자동 업로드
4. 예약 업로드로 최적 시간에 자동 게시

---

## 4. 타겟 사용자

**주요 타겟:** 인스타그램을 운영하고 싶지만 시간이 없는 카페/식당/베이커리 소사장님

| 항목 | 내용 |
|------|------|
| 연령대 | 25~50대 소상공인 |
| 업종 | 카페, 식당, 베이커리, 디저트 가게 |
| 특징 | 스마트폰은 잘 다루지만 SNS 마케팅은 어려워함 |
| 페인포인트 | 매일 올려야 한다는 걸 알지만 귀찮고 시간이 없음 |

## 5. 핵심 가치 제안

| 가치 | 설명 |
|------|------|
| 시간 절약 | 업로드에 걸리는 시간 10분 → 1분 이내로 단축 |
| 전문적인 콘텐츠 | AI가 업종/분위기에 맞는 캡션 자동 생성 |
| 꾸준한 운영 | 예약 업로드로 공백 없이 계정 운영 |
| 저렴한 비용 | 대행사 대비 1/10 수준의 비용 |

---

## 6. 서비스 범위 (MVP)

### 포함
- 이메일 / 구글 / 카카오 소셜 로그인
- 사진 업로드 + AI 캡션 생성
- 인스타그램 계정 연동 (Meta API)
- 즉시 업로드 + 예약 업로드
- 업로드 히스토리 관리

### 제외 (추후 추가)
- 분석 대시보드 (팔로워 증가, 조회수)
- 멀티 계정 관리
- 콘텐츠 캘린더
- AI 이미지 편집
- 리뷰 자동 답글
