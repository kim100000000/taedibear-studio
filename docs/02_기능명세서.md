## 2. 기능 상세

### F-01. 회원가입 / 로그인

**설명:** 이메일과 비밀번호로 계정을 생성하고 로그인합니다.

| 항목 | 내용 |
|------|------|
| 입력값 | 이름, 이메일, 비밀번호 (8자 이상) |
| 유효성 검사 | 이메일 형식, 비밀번호 강도, 중복 이메일 확인 |
| 보안 | bcrypt로 비밀번호 암호화, JWT 토큰 발급 |
| 토큰 유효기간 | 7일 |

**예외 처리:**
- 중복 이메일: "이미 사용 중인 이메일이에요."
- 잘못된 비밀번호: "이메일 또는 비밀번호가 올바르지 않아요."

---

### F-02. 소셜 로그인

**설명:** 구글, 카카오, 네이버 계정으로 간편 로그인합니다.

| 항목 | 내용 |
|------|------|
| 지원 플랫폼 | Google OAuth 2.0, Kakao REST API, Naver REST API |
| 신규 사용자 | 자동으로 계정 생성 후 로그인 |
| 기존 사용자 | 소셜 ID로 계정 조회 후 로그인 |
| 토큰 발급 | 로그인 성공 시 JWT 발급 후 대시보드 이동 |
| 이메일 미제공 시 | `kakao_<id>@kakao.taedibear.local` / `naver_<id>@naver.taedibear.local` 형식으로 내부 이메일 생성 |
| 구현 방식 | Spring Boot — GoogleOAuthClient, KakaoOAuthClient, NaverOAuthClient (WebClient 직접 호출) |

---

### F-03. 인스타그램 계정 연동

**설명:** Meta Graph API를 통해 사용자의 인스타그램 계정을 연동합니다.

| 항목 | 내용 |
|------|------|
| 방식 | Meta OAuth 2.0 |
| 필요 권한 | `instagram_basic`, `instagram_content_publish` |
| 저장 정보 | instagram_user_id, username, access_token, 만료 시간 |
| 토큰 갱신 | 만료 7일 전 자동 갱신 |

**제약:**
- 인스타그램 비즈니스 계정 또는 크리에이터 계정만 API 사용 가능
- 개인 계정은 연동 불가 (안내 메시지 표시)

---

### F-04. 사진 업로드

**설명:** 사용자가 가게 사진을 업로드합니다.

| 항목 | 내용 |
|------|------|
| 지원 형식 | JPG, PNG, WEBP |
| 최대 용량 | 10MB |
| 저장 방식 | AWS S3 (또는 Cloudinary) |
| 업로드 방식 | 드래그&드롭, 파일 선택, 모바일 카메라 촬영 |
| 미리보기 | 업로드 전 이미지 미리보기 제공 |

**인스타그램 이미지 규격:**
- 정사각형: 1080 x 1080px 권장
- 가로형: 1080 x 566px
- 세로형: 1080 x 1350px

### F-05. AI 캡션 + 해시태그 생성

**설명:** Google Gemini API를 통해 업종에 맞는 캡션과 해시태그를 자동 생성합니다.

| 항목 | 내용 |
|------|------|
| 사용 API | Google Gemini (gemini-2.5-flash) |
| 입력값 | 이미지 URL, 업종, 분위기 (선택) |
| 출력값 | 캡션 (150자 내외), 해시태그 (10~15개) |
| 수정 기능 | 생성된 캡션 직접 수정 가능 |
| 재생성 | 마음에 안 들면 재생성 가능 (최대 3회) |

**프롬프트 전략:**
- 업종 정보를 포함하여 맞춤형 캡션 생성
- 감성적이고 자연스러운 한국어 문체 적용
- 인기 해시태그 포함 (업종 + 지역 + 감성 태그 조합)

### F-06. 즉시 인스타 업로드

**설명:** 작성된 게시물을 바로 인스타그램에 업로드합니다.

| 항목 | 내용 |
|------|------|
| 사용 API | Meta Graph API - Content Publishing |
| 업로드 흐름 | 이미지 컨테이너 생성 → 게시물 발행 |
| 소요 시간 | 약 3~10초 |
| 성공 시 | 인스타 게시물 ID 저장, 히스토리에 기록 |
| 실패 시 | 오류 메시지 표시 + 재시도 버튼 |

### F-07. 예약 업로드

**설명:** 원하는 날짜와 시간에 자동으로 인스타그램에 업로드되도록 예약합니다.

| 항목 | 내용 |
|------|------|
| 최소 예약 시간 | 현재 시간 + 10분 이후 |
| 예약 변경 | 업로드 전까지 변경/취소 가능 |
| 자동 실행 | Spring @Scheduled(cron = "0 * * * * *") — 1분 단위 실행 |
| 실패 시 재시도 | 최대 3회 자동 재시도 |
| 알림 | 업로드 성공/실패 시 알림 (추후) |

|------|------|

| 컴포넌트 | `ThemeToggle` 버튼 (🌙/☀️) — NavBar 및 랜딩 페이지 헤더에 노출 |

### F-14. 온보딩 플로우

**설명:** 신규 사용자의 첫 로그인 시 서비스 사용 방법을 4단계 모달로 안내합니다.

| 항목 | 내용 |
|------|------|
| 트리거 | 대시보드 첫 방문 시 (localStorage `onboarding_seen_<userId>` 키 기준) |
| 단계 수 | 4단계 (환영 → 사진 업로드 → 예약 설정 → 시작) |
| 컴포넌트 | `OnboardingModal` — 도트 인디케이터, 이전/다음/건너뛰기 버튼 |
| 노출 횟수 | 계정당 1회, 건너뛰어도 재노출 안 됨 |

### F-15. 콘텐츠 캘린더

**설명:** 예약된 게시물을 월간 달력 형식으로 시각화하고 드래그&드롭으로 일정을 조정합니다.

| 항목 | 내용 |
|------|------|
| 위치 | `/calendar` (P-11) |
| 데이터 소스 | `GET /api/scheduled` — 기존 예약 API 재사용 (새 백엔드 API 없음) |
| 보기 방식 | 월간 달력 뷰 (7열 CSS Grid) |
| 상태 색상 | 예약 중=파랑, 업로드 완료=초록, 실패=빨강 (CSS 커스텀 변수 `--cal-*`) |
| 드래그&드롭 | `pending` 상태 항목만 드래그 가능, `PUT /api/scheduled/:id` 호출 |
| 시간 보존 | 드롭 시 원본 HH:MM 유지, 날짜만 변경 |
| 10분 제약 | 현재 시간 + 10분 이전 날짜로 드롭 불가 |
| 상세 모달 | 클릭 시 이미지, 캡션, 상태, 시간 표시 + 예약 취소 버튼 |
| 다크모드 | `[data-theme='dark']`에 `--cal-*` 다크 변수 별도 정의 |
| 다국어 | ko/en 번역 (`calendar.weekdays`, `calendar.legend.*` 등) |

### F-16. AI 이미지 편집

**설명:** 이미지 선택 후 업로드 전 Canvas API 기반으로 편집하는 단계를 추가합니다.

| 항목 | 내용 |
|------|------|
| 위치 | `/upload/edit` (P-12), `/upload` 다음 단계로 삽입 |
| 편집 방식 | 브라우저 Canvas API — 백엔드 없음, S3 업로드는 편집 완료 후 수행 |
| 비율 크롭 | 원본 / 1:1 / 4:5 / 1.91:1 (중앙 기준 자동 계산) |
| 슬라이더 | 밝기(brightness) / 대비(contrast) / 채도(saturation) — 범위 0~200, 기본 100 |
| 필터 프리셋 | 감성 / 밝음 / 빈티지 / 선명 / 따뜻함 (각각 brightness/contrast/saturation 조합) |
| 편집 초기화 | 슬라이더·필터를 기본값(100/100/100)으로 리셋 |
| 내보내기 | `canvas.toBlob()` → JPEG 92% 품질 → `POST /api/posts/upload` → CaptionPage |
| 다크모드 | `--bg-input`, `--border-color` 등 기존 변수 활용 |
| 다국어 | ko/en 번역 (`editor.*` 키) |

**업로드 플로우 변경:**
- 기존: UploadPage → `uploadImage(file)` → CaptionPage
- 변경: UploadPage → /upload/edit (파일 ObjectURL 전달) → ImageEditorPage → `uploadImage(editedBlob)` → CaptionPage

### F-17. 분석 대시보드 (자체 데이터 기반)

**설명:** Meta API 없이 서비스 DB 데이터만으로 업로드 현황을 시각화합니다.

| 항목 | 내용 |
|------|------|
| 위치 | `/analytics` (P-13), NavBar에 "분석" 메뉴 추가 |
| 백엔드 | `GET /api/analytics/summary` — AnalyticsController/Service 신규 구현 |
| 차트 라이브러리 | recharts (별도 `npm install recharts` 필요) |
| 월별 업로드 추이 | 최근 12개월 bar chart (빈 달 0으로 표시) |
| 요일별 패턴 | 업로드 완료(posted) 기준 요일별 bar chart |
| 업로드 성공률 | posted / (posted + failed) donut chart |
| 예약 비율 | 예약 경험 post / 전체 post donut chart |
| 이번 달 요약 | 업로드 수 / 성공률 / 예약 비율 stat 카드 3개 |
| 다크모드 | 차트 색상 CSS 변수 + recharts Tooltip 스타일 대응 |
| 다국어 | ko/en 번역 (`analytics.*` 키) |

**백엔드 JPQL 쿼리:**
- `YEAR/MONTH(p.createdAt)` grouping으로 월별 집계
- `FUNCTION('DAYOFWEEK', p.postedAt)` grouping으로 요일별 집계 (MySQL)
- `countScheduledPostsByUserId` — distinct postId 카운트로 예약 비율 산출
