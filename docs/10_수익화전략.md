# 10. 수익화 전략

작성일: 2026-07-06 | 상태: 초안 (CHECKLIST.md "수익화 구조 확정" 내용을 기반으로 확장)

---

## 1. 전제: 우리가 파는 것은 "캡션"이 아니라 "시간"이다

타깃 고객(소상공인 사장님)은 캡션 한 줄의 품질보다 **"SNS에 신경 쓰지 않아도 가게 홍보가 돌아가는 상태"**에 돈을 낸다. 가격 설정, 기능 배치, 마케팅 메시지 모두 이 관점에서 정렬해야 한다. "AI가 글을 잘 써줘요"가 아니라 "사진만 찍으세요. 나머지는 태디베어가 합니다"가 파는 물건이다.

이 관점에서 기능별 지불 의사(willingness to pay)를 추정하면:

| 기능 | 사장님 입장의 가치 | 지불 의사 |
|---|---|---|
| 캡션 생성 | "고민 시간 10분 절약" | 낮음 — ChatGPT 무료 대체재 존재 |
| 예약 발행 | "밤에 몰아서 준비, 낮에 자동 발행" | 중간 |
| 자동 발행 + 리뷰 답글 | "손 안 대도 계정이 살아있음" | **높음 — 대체재가 사람(직원/대행사)** |
| 분석 리포트 | "뭐가 먹히는지 알려줌" | 중간 (직접 과금보다 리텐션 장치) |

→ **결론: Pro의 핵심 소구점은 무제한 캡션이 아니라 "자동화 묶음"이어야 한다.** 무제한 크레딧은 Pro의 여러 혜택 중 하나로 내리고, 리뷰 자동 답글(Phase 4-3)·멀티 계정·인사이트를 Pro 전용 또는 Pro 우선으로 배치하는 것을 검토할 것.

## 2. 확정된 구조 (요약)

| 항목 | 내용 |
|---|---|
| Free | 가입 5크레딧(기본 3 + 온보딩 2), 광고 시청 충전 1일 2회, 월간 무료 크레딧 지급, 보유 상한 10 |
| Pro | 월 9,900원, 무제한 생성, 광고 제거 |

이 구조는 유지하되, 아래는 그 위에 얹는 전략이다.

## 3. 단위 경제성 (unit economics)

**원가 구조가 극단적으로 유리하다.** 캡션 1회 생성의 변동비는 Gemini 2.5 Flash 호출 1~2회 + 이미지 분석으로, 1회당 수 원 수준. S3/Railway/DB는 대부분 고정비.

- Free 유저 1명의 월 최대 원가: 월간 지급 + 광고 충전을 다 써도 크레딧 수십 개 = **수백 원 미만**
- Pro 유저 1명(월 9,900원)의 손익분기 사용량: 월 수천 회 생성 — 현실적으로 도달 불가능

→ **함의 1**: 무료 체험을 아낄 이유가 없다. 크레딧 정책의 목적은 원가 방어가 아니라 **"부족함을 느끼게 하는 것"**이다. 지금의 상한 10개 정책은 올바르다.
→ **함의 2**: 마진의 병목은 API비가 아니라 **결제 수수료(토스 약 3%대) + 고객 획득 비용(CAC)**이다. 수익화의 승부처는 원가 절감이 아니라 전환율과 유지율.

## 4. 가격 전략

### 4-1. 9,900원의 포지셔닝
- 비교 대상은 SaaS가 아니라 **사람**이다: SNS 대행은 월 30~50만 원, 아르바이트 1시간 1만 원+. "대행사 1/30 가격" 프레임이 유효하다.
- 국내 소상공인 대상 구독의 심리적 마지노선이 1만 원 언저리라는 점에서 첫 가격으로 적절. **당분간 가격 인상보다 전환율 데이터 축적이 우선.**

### 4-2. 연간 플랜 (도입 권장, 우선순위 상)
- 연 99,000원 (2개월 무료, 월 8,250원 꼴). 구현 비용이 낮고(validUntil 365일) 효과가 확실한 순서: **현금 선수취 + 이탈 방지 + LTV 확정.**
- 소상공인은 "월 구독 해지 깜빡함"에 민감하므로, 연간 결제가 오히려 신뢰를 줄 수 있다 ("1년에 한 번만 신경 쓰세요").

### 4-3. 중간 단계: 크레딧 팩 (검토)
- 구독 거부감이 있는 유저용 일회성 구매: 30크레딧 3,300원 등.
- 장점: 구독 전 결제 심리 장벽을 낮추는 디딤돌. 단점: Pro 전환을 잠식(cannibalize)할 수 있음.
- **권장: 당장 도입하지 말 것.** Pro 전환율 데이터를 먼저 보고, "크레딧 소진 후 이탈" 세그먼트가 크면 그때 도입.

### 4-4. 향후 상위 플랜 (Phase 5 연계)
- Business (가칭, 월 29,000원대): 멀티 계정 3개+, 리뷰 자동 답글 무제한, 팀 계정 — Phase 5 팀 계정 구현과 함께.
- 지금은 만들지 않는다. 플랜이 3개가 되면 오히려 선택 마비가 온다. **유저 100명까지는 Free/Pro 2단 유지.**

## 5. 전환 퍼널 설계

수익 = 방문 → 가입 → 활성화 → (크레딧 소진) → 결제. 단계별 장치:

### 활성화 (aha moment)
- aha moment 정의: **"내 가게 사진으로 만든 캡션이 실제 인스타에 올라간 순간".** 온보딩 보너스 +2는 이 순간까지 도달시키는 연료다.
- 가입 후 첫 캡션 생성까지의 시간을 관리자 대시보드에서 추적할 것 (24시간 내 첫 생성 비율이 북극성 지표).

### 크레딧 소진 시점 = 최대 전환 기회
- 크레딧 0개가 됐을 때가 지불 의사가 가장 높은 순간. 이때 노출할 것: "이번 달 캡션 N개 생성, 예약 M건 — Pro면 무제한이에요" 같은 **개인화된 사용 실적**과 함께 업그레이드 모달.
- 광고 충전(하루 2회)은 이 긴장을 적절히 완화하면서도 "매일 광고 보는 귀찮음"을 누적시킨다 — 의도된 마찰이므로 더 후하게 풀지 말 것.

### 결제 직전 이탈 방어
- 토스 결제창 진입 후 이탈 비율 추적. 첫 결제 한정 할인(첫 달 4,950원 등)은 전환율 데이터가 쌓인 뒤 A/B 소재로.

## 6. 수익 채널별 전략

### 6-1. Pro 구독 (주력, 매출의 80%+ 목표)
위 4·5절 참고. 핵심 지표: Free→Pro 전환율 (목표: 초기 2~3%, 성숙기 5%), 월 이탈률 (목표: 10% 미만).

### 6-2. 광고 (AdSense) — 보조 채널, 기대치 낮게
- 현실적 기대: 국내 CPM 기준 일 활성 수백 명 규모에서 **월 수만 원 수준.** 주 수익원이 될 수 없다.
- 광고의 진짜 역할 2가지: (1) 리워드 광고로 Free 유저에게 "무료로 쓰는 대신 광고"라는 공정한 거래 프레임 제공, (2) "Pro는 광고 없음"이라는 업그레이드 동기.
- 주의: 서비스 UI에 배너를 덕지덕지 붙이면 "저렴한 서비스" 인상 → 리워드 광고(크레딧 충전 시) 외 배너는 최소화 권장.

### 6-3. 워터마크 크레딧 보상 (Phase 5, 저비용 고효율)
- 구조: 캡션 끝에 자발적으로 홍보 문구/해시태그(예: "🐻 caption by Taedibear Studio")를 포함하면 크레딧 +1.
- 이것은 광고비 없는 **바이럴 루프**다: 사장님 팔로워(= 다른 사장님일 확률이 높은 로컬 네트워크)에게 노출 → CAC 0원 유입.
- 크레딧 원가는 수 원이므로 보상을 아끼지 말 것. 단, 남용 방지로 "posted 상태로 실제 발행 확인 후 지급" + 1일 1회 제한.
- 구체 구현은 7절 참고.

### 6-4. B2B 대행사 팀 플랜 (유저 확보 후)
- 마케팅 대행사는 계정 수십 개를 관리하므로 멀티 계정(Phase 4-1)이 이미 기반이다.
- 좌석(seat) 기반보다 **관리 계정 수 기반 과금**이 대행사 원가 구조와 맞는다 (예: 계정 10개 월 79,000원).
- 영업 채널: 크몽/숨고의 SNS 대행 판매자, 지역 소상공인 카페. 콜드 영업보다 "대행사가 우리 서비스로 만든 결과물"을 포트폴리오로 쓰게 하는 제휴가 현실적.
- 착수 조건: **MAU 500+ 또는 인바운드 문의 발생 시.** 그 전에는 시기상조.

## 7. 워터마크 크레딧 보상 — 구현 스케치

1. 캡션 편집 화면에 토글: "홍보 문구 넣고 크레딧 받기 (+1)" — 켜면 캡션 끝에 문구 자동 추가, 미리보기에 표시.
2. 발행 성공(status=posted) 시점에 서버가 캡션에 문구 포함 여부를 확인하고 크레딧 지급 (posts에 `watermark_opted` 플래그, 지급 이력 기록해 중복 방지).
3. 제한: 1일 1회, 보유 상한 10 그대로 적용.
4. 문구는 서버 설정으로 관리 (짧은 버전/해시태그 버전 A/B 가능).

예상 작업량: 백엔드 필드 1개 + 지급 로직 + 프론트 토글 — 반나절 규모. **Phase 5에서 관리자 대시보드 다음으로 우선순위 높음** (수익화 실험 중 가장 싸고 빠름).

## 8. 리스크와 방어

| 리스크 | 내용 | 방어 |
|---|---|---|
| 플랫폼 의존 | Meta API 정책 변경/심사 탈락이 곧 서비스 중단 | 앱 심사 요건(개인정보처리방침, 데이터 삭제 콜백) 선제 충족. 장기적으로 네이버 플레이스/카카오 채널 등 채널 다변화 |
| 대체재 | ChatGPT에 무료로 시키면 됨 | 경쟁력은 생성이 아니라 **연동+예약+자동화 파이프라인**. 마케팅에서도 생성 품질보다 자동화를 강조 |
| AdSense 승인 지연 | 콘텐츠성 페이지 부족으로 반려 가능 | 승인 실패해도 손익 영향 미미 (6-2절). 카카오 애드핏 등 대안 존재 |
| 결제 이탈/환불 | 소상공인의 구독 피로 | 연간 플랜 + "언제든 해지" 명시 + 해지 시 남은 기간 유지로 신뢰 확보 |
| 크레딧 어뷰징 | 다계정 가입으로 무료 크레딧 수확 | 이메일 인증 + 광고 충전 최소 간격(구현됨) + 관리자 대시보드에서 이상 패턴 모니터링 |

## 9. 단계별 실행 로드맵

**Stage 0 — 지금 (유저 ~0명): 측정 준비**
- 관리자 대시보드로 가입/사용/결제 흐름 가시화 (완료: Phase 5-1)
- Meta 앱 심사 통과 → 일반 유저 연동 개방 (수익화의 전제 조건)

**Stage 1 — 첫 100명: 전환 검증**
- 워터마크 크레딧 보상 출시 (바이럴 루프 가동)
- 크레딧 소진 시 개인화 업그레이드 모달
- 측정: 24h 내 첫 생성률, 크레딧 소진 도달률, Free→Pro 전환율

**Stage 2 — ~500명: 매출 다지기**
- 연간 플랜 출시
- AdSense 승인 및 리워드 광고 정착
- 전환율 낮으면: Pro 혜택 재배치(자동화 기능을 Pro로) 실험

**Stage 3 — 500명+: 확장**
- B2B 대행사 플랜 영업 개시
- Business 플랜 (팀 계정과 함께)
- 업종 확장(헬스장/미용실/네일샵)은 업종별 캡션 템플릿 + 랜딩페이지부터
